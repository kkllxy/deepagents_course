# 00｜课程总览

## 课程目标

这套课不是把 DeepAgents 当成“聊天机器人库”来讲，而是把它当成一个长任务 Agent 工程底座来讲。

最终你要能做出一个最小可用系统：

```text
人工排查记录
  -> DeepAgents 拆 claim
  -> 调日志/DB/代码只读工具核实
  -> 生成证据链
  -> 输出 runbook Markdown
  -> Codex 审查并合并知识库
```

## 15 讲目录

| 讲次 | 标题 | 核心能力 |
|---|---|---|
| 01 | Agent Harness 与第一段代码 | 理解 harness，不把它当普通聊天 bot |
| 02 | DeepAgents / LangChain / LangGraph 关系 | 搞清运行时、组件层、harness 分层 |
| 03 | `create_deep_agent` 最小 Demo | 跑通第一个 Agent |
| 04 | 默认工具与上下文工程 | todo、文件、grep、execute、task |
| 05 | Backend 后端 | 文件、状态、memory 存在哪里 |
| 06 | 文件系统上下文 | 大结果落文件，小摘要进上下文 |
| 07 | Sandbox 沙箱 | 安全运行代码和 shell |
| 08 | 自定义 Tool 开发 | 接日志、DB、API、仓库分析 |
| 09 | Memory 记忆 | filesystem-backed memory 与 RAG 区别 |
| 10 | Subagent 子智能体 | 多分支任务拆解 |
| 11 | Prompt / Instructions | 行为契约和输出 schema |
| 12 | Human-in-the-loop | 高危动作审批 |
| 13 | 权限模型 | 只读、白名单、路径隔离 |
| 14 | Trace / Debug / Eval | 可复盘、可回归 |
| 15 | 部署与成本控制 | CLI、服务化、预算、失败恢复 |

## 两个实战项目

- 实战一：代码仓库分析 Agent。
- 实战二：排查记录核实 Agent。

## 掌握标准

不是“看懂 API”，而是你能回答：

- 这个 Agent 能看哪些文件？
- 哪些工具只读，哪些需要审批？
- 它为什么下这个结论？
- 证据在哪里？
- 工具失败时怎么办？
- 如何防止 memory 污染？
- 如何接到 Codex 工作流？
