# 04｜默认工具与上下文工程

## 本讲目标

理解 todo、文件系统、grep/glob、execute、task 怎么解决长任务上下文问题。

## 核心内容

- todo 让 Agent 显式管理计划。
- 文件系统让大结果落盘，避免全部塞进上下文。
- grep/glob 让 Agent 在仓库中按需找文件。
- execute 只有在安全 backend/sandbox 下才应该开放。
- task 用于委派 subagent。


## 示例 / 模板

```text
/work/input.md
/work/claims.json
/evidence/logs.json
/evidence/db-result.json
/output/verification-report.md
/output/runbook.md
```

## 工程注意点

- 不要只追求 demo 跑通，要关注权限、证据、失败处理和可复盘。
- 所有真实日志、数据库、shell 命令都应先通过 mock 或 sandbox 验证。
- 输出尽量结构化，方便 Codex 后续读取和整理。

## 面试回答

> 默认工具的价值是上下文工程。todo 管计划，文件系统管中间产物，grep/glob 管搜索，execute 管命令执行，task 管子任务。

## 本讲练习

把本讲能力应用到“排查记录核实 Agent”里，写出你会暴露给 Agent 的工具、路径权限和输出字段。
