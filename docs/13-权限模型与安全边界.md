# 13｜权限模型与安全边界

## 本讲目标

只读优先、最小权限、路径隔离。

## 核心内容

- 把 Agent 权限分成 L0 纯推理、L1 只读、L2 写临时文件、L3 sandbox execute、L4 写 memory/PR、L5 生产写操作。
- DB tool 只允许 SELECT，限制 schema、行数、超时。
- 日志 tool 限服务、时间范围、返回条数并脱敏。


## 示例 / 模板

```text
/input       只读
/work        可写临时文件
/evidence    可写证据
/output      可写报告
/memory      读，写需审批
/secrets     不挂载
```

## 工程注意点

- 不要只追求 demo 跑通，要关注权限、证据、失败处理和可复盘。
- 所有真实日志、数据库、shell 命令都应先通过 mock 或 sandbox 验证。
- 输出尽量结构化，方便 Codex 后续读取和整理。

## 面试回答

> Agent 权限要按能力分层。不要相信模型永远守规矩，要用工具、backend、sandbox 和审批把边界写死。

## 本讲练习

把本讲能力应用到“排查记录核实 Agent”里，写出你会暴露给 Agent 的工具、路径权限和输出字段。
